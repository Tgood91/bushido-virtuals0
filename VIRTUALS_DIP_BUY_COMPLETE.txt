WHAT THIS JOB DOES
================================================================================

Every hour, this job:

1. Checks the current price of BASE_VIRTUALS token
2. Compares it to the price from 12 hours ago
3. Calculates the percentage change
4. If price dropped -4% or more: AUTOMATICALLY SWAPS $0.025 USDC → VIRTUALS
5. Posts the result to degen.virtuals.io
6. Logs everything with transaction hash

COMPLETELY AUTONOMOUS. No manual action required.


QUICK START (5 MINUTES)
================================================================================

STEP 1: Add Environment Variables
---------------------------------
Create or edit your .env file and add:

    AGENT_WALLET_ADDRESS=0x...your_wallet...
    AGENT_PRIVATE_KEY=0x...your_key...
    ALCHEMY_API_KEY=alchemy_xxx...

Getting these:
- AGENT_WALLET_ADDRESS + AGENT_PRIVATE_KEY = Your ACP agent's wallet (should already exist)
- ALCHEMY_API_KEY = Free from https://www.alchemy.com (takes 2 minutes to sign up)


STEP 2: Copy Job Files
---------------------------------
Copy these files to your ACP agent:

    virtuals-dip-buy.js → your-agent/handlers/
    virtuals-dip-buy.config.ts → your-agent/jobs/


STEP 3: Validate Setup
---------------------------------
Run the test script to check if everything is configured:

    node test-setup.js

Expected output:
    ✓ Handler file found
    ✓ Config file found
    ✓ AGENT_WALLET_ADDRESS is set
    ✓ AGENT_PRIVATE_KEY is set
    ✓ ALCHEMY_API_KEY is set
    ✓ Wallet address format valid
    ✓ ethers installed
    ✓ CoinGecko API reachable
    ✓ Alchemy API reachable


STEP 4: Test in Dry-Run Mode (SAFE)
---------------------------------
Open handlers/virtuals-dip-buy.js and find line ~30:

    DRY_RUN: false,

Change it to:

    DRY_RUN: true,

Then run:

    node handlers/virtuals-dip-buy.js

You should see output like:
    📍 [2025-01-15T14:32:45Z] JOB: virtuals-dip-buy
    📊 VIRTUALS Price: $2.15 (12h: $2.24)
    📉 Change: -3.92% over 12h
    ✗ No trigger (-3.92% > -4%)

If it says "No trigger" = Everything is working!


STEP 5: Enable Live Trading
---------------------------------
Open handlers/virtuals-dip-buy.js and change back:

    DRY_RUN: false,

Then register the job with your ACP scheduler. In your main agent file (like agent.ts), add:

    import { registerVirtualsDipBuy } from "./jobs/virtuals-dip-buy.config.js";

    // In your initialization function:
    registerVirtualsDipBuy();


STEP 6: Monitor
---------------------------------
Watch the logs to verify it's running:

    tail -f logs/agent.log | grep virtuals-dip-buy

Or if using pm2:

    pm2 logs seykota-agent


CONFIGURATION PARAMETERS
================================================================================

All values are in handlers/virtuals-dip-buy.js around line 9-26:

    TOKEN_IN: "0x833589fCD6eDb6E08f4c7C32D4f71b1566dA3DED"
    └─ This is USDC on Base (don't change)

    TOKEN_OUT: "0x580E0b90fCA6Fb1b59BA4f9D66eC0c1D39c35DEb"
    └─ This is VIRTUALS on Base (don't change)

    SWAP_AMOUNT_USD: 0.025
    └─ Amount to swap ($0.025). Change here if you want larger/smaller swaps

    PRICE_DROP_THRESHOLD: -0.04
    └─ Trigger when price drops -4%. Change to -0.05 for -5%, -0.03 for -3%, etc.

    LOOKBACK_HOURS: 12
    └─ Compare price over 12 hours. Change to 24 for daily, 6 for 6-hour, etc.

    CHECK_INTERVAL: "0 * * * *"
    └─ Run every hour at :00. Change to "*/30 * * * *" for every 30 minutes

    MAX_SLIPPAGE_PCT: 0.01
    └─ Allow max 1% price slippage. Increase to 0.02 if swaps keep failing

    MIN_BALANCE_USDC: 0.05
    └─ Don't swap if balance < $0.05. Change if you want higher/lower safety threshold

    DRY_RUN: false
    └─ Set to TRUE to test without spending money

    POST_TO_DEGEN: true
    └─ Set to FALSE if you don't want to post signals


CRON SCHEDULE EXAMPLES
================================================================================

Change CHECK_INTERVAL to adjust frequency:

    "0 * * * *"          = Every hour (recommended)
    "*/30 * * * *"       = Every 30 minutes
    "0 */6 * * *"        = Every 6 hours
    "0 0 * * *"          = Daily at midnight UTC
    "0 8 * * *"          = Daily at 08:00 UTC
    "0 0 * * 1"          = Weekly (Monday at midnight)

TROUBLESHOOTING
================================================================================

PROBLEM: "ALCHEMY_API_KEY not set"
SOLUTION: Add ALCHEMY_API_KEY to .env file (get free key from alchemy.com)

PROBLEM: "Insufficient balance"
SOLUTION: Job needs $0.05 USDC minimum in wallet. Add more USDC to your agent wallet.

PROBLEM: "Token price cannot be fetched"
SOLUTION: CoinGecko API might be temporarily down. Job will retry in next hour.

PROBLEM: "No 12h price history available"
SOLUTION: New token needs 12 hours of tracking. Wait 12 hours and try again.

PROBLEM: "DegenClaw command not found"
SOLUTION: Install with: npm install -g degenclaw

PROBLEM: "Swap fails with slippage error"
SOLUTION: Market volatility exceeded 1% max. Edit MAX_SLIPPAGE_PCT: 0.02 (for 2%)

PROBLEM: Job not running
SOLUTION: Check if enabled: true in config file. Check scheduler is registered.


HOW TO ADJUST PARAMETERS
================================================================================

To swap MORE money per dip:
    Open: handlers/virtuals-dip-buy.js, line ~15
    Change: SWAP_AMOUNT_USD: 0.025
    To: SWAP_AMOUNT_USD: 0.05  (for $0.05 swaps)

To trigger on smaller dips:
    Open: handlers/virtuals-dip-buy.js, line ~16
    Change: PRICE_DROP_THRESHOLD: -0.04
    To: PRICE_DROP_THRESHOLD: -0.03  (for -3% instead of -4%)

To check more frequently:
    Open: handlers/virtuals-dip-buy.js, line ~17
    Change: LOOKBACK_HOURS: 12
    To: LOOKBACK_HOURS: 6  (check 6-hour drops instead of 12-hour)

To allow more price slippage:
    Open: handlers/virtuals-dip-buy.js, line ~22
    Change: MAX_SLIPPAGE_PCT: 0.01
    To: MAX_SLIPPAGE_PCT: 0.02  (allows up to 2% slippage)

They work together:

    → Skip dip-buy to avoid conflict
