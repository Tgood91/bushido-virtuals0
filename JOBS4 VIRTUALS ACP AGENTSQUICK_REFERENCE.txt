WHAT IT DOES
================================================================================
Every hour: Check if VIRTUALS dropped -4% in 12 hours
If yes: Swap $0.025 USDC → VIRTUALS automatically
Post signal to degen.virtuals.io


SETUP (5 MINUTES)
================================================================================

1. Add to .env:
   AGENT_WALLET_ADDRESS=0x...
   AGENT_PRIVATE_KEY=0x...
   ALCHEMY_API_KEY=alchemy_xxx...

2. Copy files:
   handlers/virtuals-dip-buy.js
   jobs/virtuals-dip-buy.config.ts

3. Validate:
   node test-setup.js

4. Test (safe):
   Set DRY_RUN: true in handler
   node handlers/virtuals-dip-buy.js

5. Go live:
   Set DRY_RUN: false
   registerVirtualsDipBuy() in agent init


PARAMETERS TO KNOW
================================================================================

SWAP_AMOUNT_USD: 0.025
└─ Change this for bigger/smaller swaps

PRICE_DROP_THRESHOLD: -0.04
└─ -4% is default. Change to -0.03 for -3%, -0.05 for -5%, etc.

LOOKBACK_HOURS: 12
└─ Compare price over 12 hours. Change to 6, 24, etc.

CHECK_INTERVAL: "0 * * * *"
└─ Every hour. Change to "*/30 * * * *" for every 30 min

MAX_SLIPPAGE_PCT: 0.01
└─ Max 1% price slippage. Increase to 0.02 if failing

DRY_RUN: false
└─ Set TRUE to test without spending money


CRON SCHEDULES
================================================================================

"0 * * * *"        = Every hour (RECOMMENDED)
"*/30 * * * *"     = Every 30 minutes
"0 */6 * * *"      = Every 6 hours
"0 0 * * *"        = Daily at midnight UTC
"0 8 * * *"        = Daily at 08:00 UTC


WHAT HAPPENS WHEN TRIGGERED
================================================================================

Hour 1: Price check
        Current: $2.10, 12h ago: $2.19 → -4.05% ✓

Hour 2: Balance check
        USDC: $0.18 available ✓

Hour 3: Execute swap
        Input: $0.025 USDC
        Output: ~0.0119 VIRTUALS
        Gas: ~$0.001

Hour 4: Confirm TX
        Hash: 0xabcd1234...
        Block: 15,234,567

Hour 5: Post signal
        Message to degen.virtuals.io

DONE ✓ Back to hourly checks

TROUBLESHOOTING
================================================================================

"ALCHEMY_API_KEY not set"
→ Add ALCHEMY_API_KEY to .env

"Insufficient balance"
→ Job needs $0.05 USDC minimum. Fund wallet.

"Token price cannot be fetched"
→ CoinGecko API down. Retries next hour.

"No 12h price history"
→ New token needs 12h data. Wait and retry.

"Swap fails with slippage"
→ Increase MAX_SLIPPAGE_PCT: 0.02
